# 驱动安装包：改为「不限内核版本」

## 一句话

`installer/rock-5.7.1-6.2.35-V1.6.7-不限内核.aio.run` 是**同一份驱动源码**，
只把安装包里**写死目标内核版本**的那处检查去掉：现在它按**安装时正在运行的内核**
现编内核模块，任何内核都能装，不再要求目标机停在某个特定内核上。

## 原来的限制在哪

`.aio.run` 解出来的包里，`pack_all_in_one/package/install_env_check.sh`
会在**打包那一刻**把当前内核名写进 preinst 脚本：

```bash
cat>preinsts/00_env_check.sh<<EOL
#0. check version magic
TARGET="$(uname -r)"        # ← 把“本机内核”钉死在包里
EOL
...
if [ "$TARGET" != "$CUR" ];then
	echo "This package for target($TARGET), not current($CUR)"
	exit -22                # ← 内核名对不上就直接拒绝安装
fi
```

于是产出的 `.deb` 只能装在**打包时那个内核**上；配合外部脚本把 GRUB 默认项锁到
那个内核，才出现「升级内核后没 `/dev/kfd`、必须锁内核」的一串麻烦。

## 改了什么

只动 `pack_all_in_one/package/` 下两个文件、共 4 行语义：

```diff
# install_env_check.sh（生成 preinst 的地方）
 cat>preinsts/00_env_check.sh<<EOL
 #0. check version magic
-TARGET="$(uname -r)"
-EOL
+# 不锁定内核版本：TARGET 留空 → 任何内核都能装
+TARGET=""
+EOL
 cat>>preinsts/00_env_check.sh<<'EOL'
 CUR=$(uname -r)
-if [ "$TARGET" != "$CUR" ];then
+if [ "$TARGET" != "" ] && [ "$TARGET" != "$CUR" ];then
```

`preinsts/00_env_check.sh`（包内已生成的那份）同步改成一样，避免任何路径回退到旧检查。

其余逻辑**一个字没动**：驱动源码、`amdgpu-5.7.0-0` 里的 KCL 兼容层、
内核 6.8 的 `DRM_DEBUG_CATEGORY` 探测修正（`drm_debug_enabled.m4`）、
固件、hyhal 用户态、udev/modprobe/hymgr.service 全部原样。

## 为什么这样就够了

驱动本来就是**在目标机上现编**的：`.aio.run` 解包 → `cmake` → 内核模块用
`/lib/modules/$(uname -r)/build` 编译 → 打 `.deb` 安装。写死 `TARGET` 只是把
「装的时候在内核 X 上」当成约束强加给使用者；去掉之后：

* 换内核（比如 HWE `6.8.0-138`、或以后升级到 6.11/6.14）→ 在新内核上重跑一次
  `.aio.run` 就会为新内核重编模块，不需要再改 GRUB 默认项；
* 需要的内核头文件与工具链（`linux-headers-$(uname -r)`、`gcc/make/cmake/autoconf/m4`）
  仍然必须有——这是编译内核模块的硬前提，与版本限制无关。

## 校验

```bash
# 1) 包里生成出来的 preinst 不再钉内核
tmp=$(mktemp -d); tail -n+1245 installer/rock-5.7.1-6.2.35-V1.6.7-不限内核.aio.run | tar -xzC "$tmp"
grep -A3 "check version magic" "$tmp"/rock-*/pack_all_in_one/package/preinsts/00_env_check.sh
#    → TARGET=""  且条件是 [ "$TARGET" != "" ] && ...

# 2) 安装（在目标机上，任意内核）
sudo bash installer/rock-5.7.1-6.2.35-V1.6.7-不限内核.aio.run
sudo reboot
/opt/hyhal/bin/hy-smi
lsmod | grep -E '^(hydcu|hyttm|hykcl)'
```

## 两个包的关系

| 文件 | 用途 |
|---|---|
| `rock-5.7.1-6.2.35-V1.6.7-内核68修正.aio.run` | 原修正版：内核 6.8 编译修正 + **仍会钉内核**（保留做对照） |
| `rock-5.7.1-6.2.35-V1.6.7-不限内核.aio.run` | **推荐**：编译修正 + 不钉内核，任何内核现编现装 |

两份的驱动源码完全一致，差别只有上面那 4 行。
